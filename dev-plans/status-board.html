What blocks the release

Gold tier: two rules, one of them external

Every Gold rule is now closed. What remains is test-coverage — the Silver ≥95% bar (QS.S1), and the real blocker since Gold requires Bronze + Silver + Gold — plus brands, which needs a PR to home-assistant/brands and is out of our hands. strict-typing is Platinum and explicitly not claimed this release.

Internal bug numbers collide with GitHub numbers

WORKITEMS uses #NNN for globally-monotonic internal bug IDs, but that is also how a GitHub reference reads — and GitHub issues and PRs share one counter. Internal #243 and #247 now collide with real dependabot PRs of the same number. Anyone reading the work items will follow those links to the wrong thing.

The 1.8 theme is still ahead

34 of 63 open items are the LLM workstreams that define this release. The bug list and the Gold walk are close to clear; the feature work has not started.
